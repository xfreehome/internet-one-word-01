Entry for the [The Internet in One Word](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b) bounty on [make.fun](https://make.fun): a program that writes one word describing the whole internet — the funniest and most fitting wins.

## The entry

> Doomscroll

One word for the whole internet: an endless feed of bad news you can't stop reading at 2am. Funny because it's true, true because we've all done it.

## Run

```sh
node main.ts   # writes /output/entry.txt (10 characters)
```

Requires Node 22.18+ (TypeScript runs as-is).
